# Production credits

- Narration: Crew Web TTS Worker, `gemini-3.8-flash-tts`, Kore voice, Traditional Chinese for Taiwan. The deployed Worker applies one fixed natural, calm, warm, conversational style to each queued take; the queue does not support per-scene emotion controls. Scene emotion notes describe editorial intent, not a verified model setting.
- Voice source files: `assets/voice/scene1.wav` through `scene7.wav`, fetched from the matching job result URLs recorded in `voice-jobs.json`. No API key is stored here.
- Typography: Noto Sans TC, subset for this video from the Google Fonts source file; distributed under SIL Open Font License 1.1. See `assets/OFL.txt`.
- Animation: GSAP library copied from the existing Crew Video Lab asset at `video-lab/examples/2026-10-31-agentdecept-brief/assets/gsap.min.js`; original license header retained.
- No stock footage, external images, or third-party music is used.
